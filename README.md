# نظام الحضور والغياب الذكي لإدارة المكاتب 📍🏢
### Smart GPS Attendance & Leave Management System (iOS, Android & Web)

تم بناء هذا النظام خصيصاً لتلبية متطلبات إدارة المكاتب وفرق العمل:
1. **تسجيل الحضور بالـ GPS الجغرافي (Geofencing):** لا يمكن تسجيل الحضور إلا إذا كان الموظف داخل النطاق الجغرافي المحدد للمكتب بالأمتار (مثلاً 100 متر).
2. **شعار وبدء وردية الـ 8 ساعات:** رسالة *"تمام كدا انت دلوقتي في العمل"* مع عداد حي تنازلي وتصاعدي لساعات العمل.
3. **قفل الانصراف (Check Out Lock):** زر الانصراف مقفل ومحمي تماماً ولا يُتاح إلا بعد إتمام الـ 8 ساعات كاملة (أو في حال وجود إذن ساعتين مسائي معتمد أو طلب انصراف طارئ بموافقة المدير).
4. **شاشة المتابعة الحية للمكتب (Live Presence Dashboard):**
   * من متواجد في المكتب الآن مع توقيت الحضور.
   * تفصيل الإجازات: **إجازة أسبوعية**، **إجازة مرضي**، **إجازة سفر ومأمورية**، **إجازة سنوية/اعتيادية**.
   * من لديه **إذن ساعتين** وموعد الإذن.
   * من غائب بدون إذن مع إمكانية الاتصال المباشر.
5. **تبويب طلب الإجازات والأذونات:**
   * تقديم طلبات الإجازات بأنواعها وإرفاق التقارير الطبية.
   * تقديم طلب **إذن الساعتين** (صباحي / مسائي / طارئ).
   * إمكانية الاعتماد والرفض الفوري للمدير.
6. **نظام الصلاحيات الشامل (Role-Based Access Control - RBAC):**
   * إمكانية التحكم الكامل في كل مسمى وظيفي (تايتل): تحديد ما يمكنه رؤيته، الوصول إليه، أو تنفيذه.

### طريقة التشغيل الفوري (Quick Start)

التطبيق يعمل الآن على المنفذ `3001`:
```bash
# رابط التطبيق على المتصفح
http://localhost:3001
```

لفتح التطبيق على هواتف الموظفين (Android و iPhone) داخل نفس شبكة المكتب:
1. احصل على عنوان IP الخاص بجهاز الكمبيوتر في الشبكة:
```bash
ifconfig | grep "inet "
```
2. افتح المتصفح على هاتف الموظف واكتب:
```text
http://<YOUR_IP>:3001
```
3. على آيفون: اضغط زر **مشاركة (Share)** ثم **"إضافة إلى الشاشة الرئيسية (Add to Home Screen)"**.
4. على أندرويد: اضغط القائمة **(⋮)** ثم **"تثبيت التطبيق (Install App)"**.

### الهيكل البرمجي (Architecture)
* `server/`: خادم Node.js / Express مع قاعدة بيانات سريعة وقوية لحفظ السجلات والإحداثيات.
* `src/`: واجهات React 19 + Tailwind CSS + Lucide Icons مع دعم كامل للغة العربية (RTL) وتصميم مخصص للموبايل والديسكتوب.
* `dist/`: الملفات المجمعة للإنتاج.
